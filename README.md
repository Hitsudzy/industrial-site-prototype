# Прототип корпоративного сайта «Компания»

Кликабельный статический прототип сайта инжиниринговой компании. Обезличен:
компания называется «Компания», логотип — нейтральный плейсхолдер, надпись
в знаке — временная, тексты — «рыба». Закрыт от индексации (`noindex, nofollow` в каждой странице и
`robots.txt`).

Чистый HTML/CSS/JS без сборки и без зависимостей: папка отдаётся как есть
(GitHub Pages или любой статический сервер). Все пути относительные, поэтому
сайт работает и из корня домена, и из подпапки `/<repo>/`.

## Как открыть локально

```sh
cd prototype
python3 -m http.server 8000
```

Открыть <http://localhost:8000/>. Двойной щелчок по `index.html` (схема
`file://`) тоже работает, но часть браузеров ограничивает `localStorage` для
`file://` — выбор концепции тогда передаётся только через параметр `?c=` в
адресе.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: первый экран + секции-плейсхолдеры (приветствие, направления, ключевые проекты, цифры, новости, партнёры, контакты с формой) |
| `project.html` | Страница проекта: заголовок, метаданные, описание работ, галерея-коллаж, связанная услуга, соседние проекты, CTA «Обсудить задачу» |
| `company.html`, `services.html`, `projects.html`, `news.html`, `licenses.html`, `partners.html`, `contacts.html`, `privacy.html` | Заглушки «раздел в разработке» в том же оформлении |

Каждая секция главной и страницы проекта помечена `data-block="<имя>"` и
`id` — по ним последующие задачи заменяют плейсхолдеры настоящей вёрсткой.

## Как устроены концепции A/B

- **A «инженерный тёмный»** — графит и тёмно-синий фон, циановый акцент,
  тонкая «чертёжная» сетка на фоне, моноширинные подписи.
- **B «корпоративный светлый»** — белый фон, тёмно-синий текст, тёмный первый
  экран и подвал, спокойный синий акцент, мягкие тени и скругления.

Механика:

1. Тема целиком задаётся токенами — CSS custom properties в
   `assets/css/tokens.css`. Блоки `:root[data-concept="a"]` и
   `:root[data-concept="b"]` переопределяют одни и те же переменные
   (цвета, радиусы, тени, сетка, шрифт подписей). Компоненты в
   `assets/css/base.css` используют только переменные, без «сырых» цветов.
2. Класс `.theme-inverse` переводит блок на «инверсную» поверхность
   (первый экран, подвал, CTA-полосы): в B это тёмно-синий фон со светлым
   текстом, в A — ещё более тёмный графит.
3. `assets/js/concept-init.js` подключён синхронно в `<head>` и до первой
   отрисовки ставит `data-concept` на `<html>`. Приоритет: параметр адреса
   `?c=a|b` → `localStorage` (ключ `proto-concept`) → по умолчанию `a`.
   Все обращения к `localStorage` обёрнуты в `try/catch`.
4. `assets/js/main.js` (с `defer`) оживляет кнопку-переключатель в правом
   нижнем углу, при переключении обновляет `data-concept`, `localStorage`,
   параметр `?c=` в адресной строке и дописывает `?c=` ко всем внутренним
   ссылкам — поэтому выбор сохраняется при переходах даже там, где хранилище
   недоступно. Ссылку вида `index.html?c=b` можно отправить, и она откроется
   сразу в нужной концепции.

Чтобы добавить токен — объявить его в обоих блоках концепций в
`tokens.css` (и в `--inv-*`, если он нужен на инверсной поверхности).

## Знак и иллюстрации

### Как поменять текст знака

Пятиугольный знак на первом экране — inline SVG в `index.html` (ищите
`class="sign hero__sign"`, над ним комментарий). Текст правится в двух местах
внутри этого `<svg>`:

1. `<text class="sign__text" …>Надёжность</text>` — то, что нарисовано;
2. `<title id="sign-title">Знак компании «Надёжность»</title>` — то, что
   читает скринридер.

Регистр задаёт CSS (в A — прописными, в B — как написано). Если слово шире
внутренней рамки, `assets/js/main.js` сам ужимает его до `data-max` (в единицах
`viewBox`). Цвета и шрифт знака — классы `.sign__*` в `assets/css/base.css` и
токены `--sign-*` в `tokens.css`; графика A и B — две группы `sign__art--a` и
`sign__art--b` в том же `<svg>`.

### Фон первого экрана и шкаф

Нарисованы кодом скриптом `tools/gen_art.py` (без растров) и лежат в
`assets/img/`:

| Файл | Где используется |
|---|---|
| `hero-a.svg`, `hero-b.svg` | фон первого экрана главной — токен `--hero-art` в `tokens.css` |
| `cabinet-a.svg`, `cabinet-b.svg` | условный «3D-шкаф» (изометрия) в галерее `project.html` |

Готовые SVG закоммичены, сборка не нужна; скрипт запускают только после
правки рисунков: `python3 tools/gen_art.py`. Картинки под концепцию
переключаются парой `<img class="only-a">` / `<img class="only-b">`.

Поверх фона лежит затемняющая подложка (`.hero__art::after` в `base.css`),
поэтому текст первого экрана держит контраст AA. Худший случай проверяет
`python3 tools/check_hero_contrast.py` (код выхода 0 — все пары ≥ 4.5:1).
В A по фону медленно проходит «сканирующая» линия; при
`prefers-reduced-motion: reduce` она скрыта.

## Шрифты

Self-hosted woff2 (только латиница и кириллица) в `assets/fonts/`,
подключаются в `assets/css/fonts.css`. Лицензии — в `CREDITS.md`.

## Доступность

Ссылка «Перейти к содержанию», видимый фокус (`:focus-visible`),
переключатель — настоящая `<button>` с `aria-label`, смена концепции
озвучивается через `role="status"`, мобильное меню с `aria-expanded` и
закрытием по Esc, `prefers-reduced-motion` отключает анимации. Контраст пар
«текст/фон» во всех токенах — не ниже WCAG AA.

## Проверка «нет внешних запросов»

```sh
python3 tools/check_external.py
```

Ищет абсолютные адреса (`http://`, `https://`, `//host`) во всех `.html`,
`.css`, `.js`, `.svg`, кроме комментариев и XML-пространств имён
(`xmlns="http://www.w3.org/..."` — это идентификатор, браузер его не
загружает). Код выхода 0 — внешних ссылок нет.
